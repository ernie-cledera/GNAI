Official website for **Global Nurses Alliance Incorporated (GNAI)**, a healthcare humanitarian non-profit organization uniting nurses, healthcare leaders, and community allies to deliver life-changing medical missions, disaster relief, livelihood programs, and health empowerment to vulnerable populations globally.

---

## 🛠️ Tech Stack & Key Features

- **Frontend:** React 18, Vite, Tailwind CSS, Lucide Icons
- **Interactive Features:**
  - 501(c)(3) Tax-Deductible Donation Calculator & Instant Receipt Modal
  - Volunteer Application & Alliance Inquiry System
  - Searchable Nevada Hospital Ambassador Directory
  - Interactive Historical Milestone Timeline (2020 – Present & Future Goals)
  - Mobile-First Ergonomic Layout with Sticky Floating Action Bar & Responsive Drawer

## 🚀 Getting Started Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ernie-cledera/GNAI.git
   cd GNAI
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
